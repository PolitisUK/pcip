# Pilot Administrator Guide

This guide is for local authority service owners, digital leads, and programme managers preparing a live pilot.

## 1. Before your pilot starts

1. Confirm your organisation users are invited in Researchers.
2. Run the first-project wizard from Dashboard to establish your first project and study.
3. Optionally run sample data from Dashboard for staff training.
4. Confirm security settings and login routes (local login and/or Microsoft Entra).
5. Verify email delivery behavior using Email outbox.

## 2. Daily administrator tasks

1. Review Dashboard metrics and onboarding progress.
2. Check Audit log for security and operational events.
3. Monitor failed invitations and re-send where needed.
4. Validate participant privacy workflows for export/deletion requests.

## 3. Pilot governance checklist

- Project has a named owner and backup administrator.
- Study has clear participant information and consent wording.
- Recruitment and inclusion criteria are documented.
- Internal notes and participant messages are used consistently.
- Retention and privacy controls are agreed.

## 4. Handling common issues

- No data visible: check user role and study access settings.
- Participant cannot join: confirm invitation is active and not revoked.
- No email received: review Email outbox and SMTP configuration.
- Access denied errors: verify permissions and organisational scope.

## 5. Recommended launch sequence

1. Complete first-project wizard.
2. Add at least one activity.
3. Add/import participants.
4. Send two test invitations to internal staff.
5. Validate submissions and message flow.
6. Start live participant recruitment.
