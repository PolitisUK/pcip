Cookie Banner and Preference Centre Wording for Citizen Centric

Effective Date: 15 August 2026

Last Updated: 15 August 2026

Version: 1.0

Operated by Politis Ltd. Questions: info@politisconsulting.co.uk. This wording must be used only for technologies actually deployed in production. Do not present analytics, marketing or preference-centre functionality as active until confirmed.

1. First-layer banner - website/researcher dashboard

Heading: Your privacy choices on Citizen Centric

We use strictly necessary cookies and similar technologies to keep Citizen Centric secure and working. If we use optional analytics or other non-essential technologies, we will ask for your choice before they are enabled. You can accept or reject optional technologies and change your choice later where a preference centre is available.

Buttons (where optional technologies are actually deployed): Accept optional | Reject optional | Manage preferences

Do not use “continued browsing means consent”. Rejecting optional technologies should be as easy as accepting them.

2. Mobile app position

Do not show a cookie-consent screen in the participant mobile app merely because the app uses secure device storage, local drafts, queued submissions or OS permissions. These are not automatically analytics/marketing cookies.

Only show an app privacy-choice screen if a non-essential SDK or similar technology requiring PECR consent is actually deployed.

If such an SDK is deployed, use: “Optional app technologies” and explain the actual technology, purpose and choice. Do not use vague references to analytics or performance tracking without naming what is really active.

3. Preference centre

Strictly necessary: Always on. Explain the actual session/security technologies in use.

Functional: Include only if a deployed technology is genuinely optional and requires a separate preference. Do not classify essential offline draft protection as optional merely because it uses local storage.

Analytics/performance: Show only when an actual non-essential analytics technology is deployed; default off until valid consent is obtained where required.

Marketing/targeting: Omit this category entirely if Citizen Centric does not deploy marketing, advertising, attribution or cross-site tracking technology.

4. Withdrawal/change wording

You can change or withdraw your choice for optional technologies at any time using the Cookie Preferences control when optional technologies are enabled. At version 1.0 no marketing/advertising tracking is active. Changing optional choices will not disable strictly necessary security or service functions.

5. Deployment requirements

• Confirm exact cookie/SDK names and providers.

• Confirm purpose and duration/expiry.

• Confirm whether PECR consent or an exemption applies.

• Confirm processing locations and any relevant international-transfer safeguards.

Website/app analytics status: operational diagnostics and security/performance telemetry are active; no marketing/advertising tracking is active.

Mobile analytics/telemetry status: operational diagnostics and security/performance telemetry only; no Google Analytics or advertising/marketing SDK is active in the participant app.

• Confirm whether any marketing/advertising technology is active.

• Insert final Cookie Policy and Privacy Policy URLs.

6. Accessibility

Cookie banners and preference controls must remain keyboard accessible, screen-reader compatible, operable at enlarged text sizes and understandable without relying on colour alone. Controls must not use pre-selected optional consent toggles.

Citizen Centric currently uses operational diagnostics, security logging and service-performance telemetry to maintain the reliability and security of the platform. This is not used for advertising, behavioural profiling or cross-site marketing. Google Analytics and marketing/advertising SDKs are not currently used in the participant mobile application. If any non-essential analytics technology requiring consent is introduced, it will be disabled by default until valid consent is obtained where PECR requires it.
