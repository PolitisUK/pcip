RESEARCH METHODOLOGY SYNTHESIS BUNDLE - VERSION 1.0

Files
-----
methodology_synthesis_report.md
    Human-readable academic synthesis with the 14 requested sections.

methodology_knowledge_base.jsonl
    One methodology-family record per line. Each record includes 21 component-level
    rules, triangulation status, and source provenance.

methodology_claim_register.jsonl
    Claim-by-claim provenance and triangulation status.

methodology_disagreements.jsonl
    Structured methodological disagreements using the requested ISSUE / CORE POSITION /
    EXTERNAL POSITION(S) / WHY THEY DIFFER / PRACTICAL CONSEQUENCE / COMBINATION / RISK format.

methodology_source_register.json
    Core and external source inventories, bibliographic metadata and quality limitations.

methodology_search_log.json
    Gap-led external search logic and what each search changed in the synthesis.

Use notes
---------
- Source IDs C01-C10 and E01-E70 are stable across all files.
- The synthesis is not a substitute for a project-specific protocol or ethics review.
- External research was selective and gap-led, not a systematic review of every field.
- AI rules distinguish source-supported methodology requirements from platform governance.
