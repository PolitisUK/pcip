# Pilot Researcher Guide

This guide is for researchers running day-to-day studies in Citizen Centric.

## 1. Getting started

1. Sign in and open Dashboard.
2. Create your project and study (or use first-project wizard).
3. Add study activities with clear prompts.
4. Add participants and enrol them into the study.
5. Send invitation links from the study participant table.

## 2. Activity design tips

- Start with one simple text activity to test workflow.
- Use clear expected response language.
- Set realistic release and due windows.
- Keep participant burden low in week one.

## 3. Running the pilot

1. Track enrolments and invitation statuses.
2. Follow participant submissions in study and participant pages.
3. Use messages for support and reminders.
4. Mark internal notes clearly when logging operational context.

## 4. Good practice for data quality

- Avoid ambiguous prompts.
- Use short, plain language for participants.
- Capture consent status changes promptly.
- Maintain accurate participant references.

## 5. Escalation points

Escalate to administrators when:

- You cannot access a study needed for delivery.
- Participant privacy or deletion requests are received.
- Repeated invitation failures occur.
- Upload evidence appears blocked by scanning controls.
