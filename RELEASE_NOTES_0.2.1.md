# Politis Civic Intelligence Platform 0.2.1

This cumulative release adds the research-management layer to the 0.1.0 production foundation.

## Main workflow
1. Create a project.
2. Add a study and select its methodology.
3. Build ordered activities with release and due offsets.
4. Create participant records and record recruitment/consent metadata.
5. Enrol participants into studies.
6. Send secure email invitations.
7. Track whether invitations were opened and accepted.

## Scope boundary
This release creates and recruits studies but does not yet provide the full participant activity-completion portal, evidence uploads, live messaging or qualitative analysis. Those belong to subsequent cumulative increments.
