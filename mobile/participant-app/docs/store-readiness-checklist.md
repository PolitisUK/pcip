# Participant App Store Readiness Checklist

## Metadata
- Final app name and subtitle approved.
- Store description reflects participant evidence, messaging, and privacy flows.
- Privacy policy URL and support URL verified.
- Age rating and content declarations reviewed.

## Compliance
- Data safety disclosures match actual storage and transmission behavior.
- Account deletion process references in-app deletion request flow.
- Consent and withdrawal language reviewed by policy/legal stakeholders.
- Accessibility review completed for key screens and dialogs.

## Assets
- Icon and splash assets exported in required store dimensions.
- App preview screenshots captured for phone form factors.
- Optional app preview video reviewed and approved.

## Release Controls
- EAS `production` profile configured and validated with a dry run build.
- Changelog prepared for release notes.
- Internal sign-off captured from engineering, product, and policy owners.
- Rollback plan documented before submission.
